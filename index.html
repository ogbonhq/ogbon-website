03 / Ogbon Platform

Switch in one line.

Use the OpenAI SDK you already have. Change the base URL and pick a model.

app.py

import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.ogbon.com/v1",
    api_key=os.environ["OGBON_API_KEY"],
)

reply = client.chat.completions.create(
    # A managed model, or one you deployed
    model="llama-3.1-8b",
    messages=history,
)

05 / Research

Latest from the lab.

Every experiment we run, with what worked, what didn’t, and the numbers behind both.

  1. E004 · In progress

    Hybrid serving of large MoE models

    Experts in system memory, everything else on one GPU. Cheaper per token than GPUs sized to fit them?

  2. E003 · Partial result

    Why AMX bf16 scales poorly across cores

    13.5 TFLOP/s at 8 threads, 5.0 at 16. Noise, kernel switching and power limits ruled out.

  3. E002 · Result

    CPU‑only language‑model serving

    7 to 20 times more per token than a loaded H100. Rejected, so we moved to hybrid serving.
